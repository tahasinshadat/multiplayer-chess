# Chess++

A C++ multiplayer chess game built using object-oriented design principles. Development is being done collaboratively through **VSCode Live Share**.

## Authors

**Tahasin Shadat**  
**Danny Peng**

## Description

This project aims to implement a fully functional multiplayer chess game in C++, replicating Chess.com. 

## Development Tools

- C++
- Visual Studio Code
- VSCode Live Share

## Status

Project is in the early development phase. Key components like board representation, piece inheritance structure, and move validation are currently being implemented.
